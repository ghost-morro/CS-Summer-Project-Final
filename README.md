# C# Password Strength Checker & Generator

## Overview

This project was developed as part of a summer programming task at Riddlesdown Collegiate. It is a C# console application that generates passwords and evaluates their strength based on defined rules.

The project was later improved after learning new programming concepts, allowing for a full refactor of the original version.

## Features

* Password strength checker
* Password generator using random character selection
* Strength scoring system based on:

  * Length of password
  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
  * Detection of sequential keyboard patterns
* Classification of passwords into:

  * Weak
  * Average
  * Strong

## Versions

This repository contains two versions of the project:

### Original Version

The initial implementation created using my early programming knowledge. This version is larger and less efficient, but fully functional.

### Improved Version

A refactored version built after learning FOR loops and improving my programming understanding. This version is significantly more efficient, reducing the codebase from approximately 1,500 lines to around 400 lines.
